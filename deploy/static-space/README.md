# AstroVision LoRA

這是目前的免費靜態 UI Preview，可操作圖片預覽、提示詞與模擬生成狀態，但不執行 GPU
推論。所有範例輸出都標示為 sample；真正的 LoRA 圖片描述功能會在 Hugging Face PRO +
ZeroGPU 部署後啟用。

- [LoRA adapter](https://huggingface.co/lee851104/gemma3-4b-astronomy-lora)
- [GitHub source](https://github.com/lee851104/lora_mars)
